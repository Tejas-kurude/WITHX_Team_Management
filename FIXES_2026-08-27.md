# Admin Panel fixes — 27 Aug 2026

## Super Admin
- Leave edit/delete access remains enabled in both UI and protected backend routes.
- Daily report listing includes Super Admin's own records together with all staff reports.

## Admin
- Admin cannot approve or reject their own leave; the UI shows "Super Admin required" and the API also blocks self-approval.
- Admin daily-report listing is restricted to the Admin's own reports.
- Admin cannot review daily reports; Admin reports are reviewable by Super Admin.

## Team Lead
- Team Lead leave approval controls are removed and the decision API rejects Team Lead access.
- Team Lead daily-report listing includes their own report plus directly supervised team members.
- Team Lead can review only direct team-member reports, never their own.
- A task assigned directly to a Team Lead can have its progress/status updated by that Team Lead.

## Tasks / network-error hardening
- Task assignee progress permissions no longer depend on the literal EMPLOYEE role.
- Existing installations must run `database/migration_v3.sql` so the task schema matches the current backend.
- Frontend and backend remain connected through `VITE_API_URL` (default `http://localhost:5000/api`).

## Frontend branding
- Replaced the old logo asset with the supplied WithX image.
- Replaced the orange brand accent with ochre/golden `#AC7D0C` / `rgb(172, 125, 12)`.
