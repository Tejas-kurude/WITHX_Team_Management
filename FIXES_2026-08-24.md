# Fixes applied — 24 Aug 2026

## Blank page fix
The Department, Leave, Daily Reports and Notifications pages were using an async Promise directly as the return value of `useEffect`. React can interpret the returned Promise as an effect cleanup value, which can crash navigation/unmount and leave the app blank. These pages now start async loading with `void load()` and show API errors in-page instead of rendering a blank screen.

## Super Admin management controls
Only `SUPER_ADMIN` can now edit/delete existing records through the management APIs and UI controls for:
- Employees
- Departments
- Tasks (administrative task fields)
- Leave requests
- Daily reports
- Notifications

Admins can still create employee/department records where previously allowed. Team Leads/Admins can still perform workflow actions such as leave decisions and report reviews. Employees can still update their own assigned task status/progress.

## Additional fixes
- Super Admin notification page can see all employee notifications, with employee names.
- Added frontend Vite TypeScript environment declarations.
- Fixed TypeScript compatibility issues (`replaceAll`, PostgreSQL query generic constraint, route param typing).
- Backend and frontend TypeScript checks pass.

## After replacing the source
Keep your existing `backend/.env` locally (it is intentionally excluded from the fixed ZIP), then run:

```powershell
npm install
npm run dev
```

If you prefer separate terminals:

```powershell
cd backend
npm install
npm run dev
```

and in another terminal:

```powershell
cd frontend
npm install
npm run dev
```
