# Requested Changes Implemented — V3

1. **Company Location & Attendance** — Admin/Super Admin location settings, Online/Offline mode, GPS permission for Offline, geofence validation, stored mode/coordinates/user/date/time.
2. **Team Lead RBAC** — team-only employee/task/attendance/report/leave/performance scope; no Admin/Super Admin creation or system settings access.
3. **Departments** — member counts, department details, head/lead assignment, search, department selection on user creation/edit, deletion blocked when members exist.
4. **Task Assignment** — individual, multiple, entire team and department assignment with per-user task records and notifications.
5. **Task Fields** — auto Task ID, title/description, assignee, department/team, creator, created timestamp, start/deadline, status, priority, completion time, optional attachment/reference URL, filters and overdue indicator.
6. **Employee/Intern IDs** — automatic permanent INT/EMP sequence IDs using a persistent counter.
7. **Additional Requirements** — search/filter, audit logs, notifications, validation, page/action RBAC, automatic timestamps, employee/intern dashboard counts, CSV reporting, profile ID display.
